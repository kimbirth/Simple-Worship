# Contributing

Thank you for helping improve SimpleWorship.

1. Create a branch from `main`.
2. Keep changes focused and do not commit credentials, certificates, user data,
   media libraries, or copyrighted Bible text.
3. Run `npm ci` and `npm run release:check`.
4. Open a pull request describing the behavior change and how it was tested.

Changes to dependencies, build scripts, packaging, GitHub Actions, or signing
configuration require especially careful review because official releases must
remain reproducible from the public repository.

By contributing, you confirm that you have the right to submit the contribution
under the project's license. Maintainers and release approvers must enable
multi-factor authentication on GitHub and SignPath.
