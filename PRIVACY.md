# Privacy policy

SimpleWorship does not contain telemetry, analytics, advertising, automatic
update checks, or cloud synchronization.

Songs, schedules, settings, backups, imported Bible packages, and media-library
references remain on the user's computer. Media files are read only when the
user selects them. A loopback-only HTTP server (`127.0.0.1`) lets the local
Electron renderer play selected media; it is not exposed to the network and is
restricted to paths authorized by the application.

This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or operating
it.

The project website, GitHub, and SignPath are separate services used to obtain
source code and releases. Their respective privacy policies apply when users
choose to visit or use those services. They are not contacted by the installed
application.
